# 🤖 Student Helping RoBot

A Telegram Bot built using Python that helps Government Exam aspirants by providing Previous Year Question Papers and Official Answer Keys.

## ✨ Features

- 📚 Previous Year Papers (PYQs)
- 📝 Official Answer Keys
- 📂 Year-wise Navigation
- 📄 Shift-wise PDFs
- 💬 Suggestions System
- 👤 User Database (SQLite)

## 🛠 Technologies Used

- Python
- python-telegram-bot
- SQLite
- Git
- GitHub
